# 校园活动积分平台 (EduPoint) - 学生移动端 (Mobile App)

基于 **Uni-app**（**Vue 3** + **Vite** + **TypeScript**）跨端开发框架构建的学生端移动应用，支持编译为 **H5 移动网页端**（首选开发目标）与 **微信小程序**。

## 📱 核心功能模块与页面颗粒度

1. **活动大厅 (`pages/activity/index`)**：
   - 浏览有效活动列表，支持状态过滤（进行中/未开始/已结束）；
   - 查看活动地点详情与地图导航路线；
   - 活动报名（名额满员时自动提示并加入候补队列）。
2. **动态扫码打卡 (`pages/activity/checkin`)**：
   - 支持扫一扫活动动态二维码唤起；
   - 获取当前手机 GPS 经纬度位置，校验是否处于打卡半径范围内；
   - 提交打卡核销，实时获得活动积分奖励。
3. **积分商城 (`pages/gift/index`)**：
   - 浏览可兑换礼品库及所需积分；
   - 填写收件人、联系电话及宿舍地址发起兑换；
   - 兑换成功实时扣分并生成提货核销码（Pickup Code）。
4. **积分排行榜 (`pages/rank/index`)**：
   - 全校学生积分榜单，展示排名、学生昵称、累计积分与我的实时排名。
5. **个人中心 (`pages/my/index`)**：
   - 学号身份绑定与个人昵称修改；
   - 当前可用积分余额与积分明细流水台账；
   - 我的活动报名与打卡记录；
   - 我的兑换订单与提货码凭据展示；
   - 我的电子荣誉证书展示与验真二维码；
   - AI 智能客服悬浮窗入口（实时业务答疑与知识库兜底）。
6. **系统通知中心 (`pages/my/notices`)**：
   - 分 Tab 展示全部 / 未读 / 已读通知；
   - 支持单条标为已读、一键全部已读、删除通知；
   - 顶部展示未读角标数量，未读条目高亮显示。

## 🚀 启动与编译指令

```bash
# 1. 安装项目依赖
npm install

# 2. 运行为 H5 移动网页版 (推荐本地开发使用，监听 5173 端口)
npm run dev:h5

# 3. 编译为微信小程序版 (编译产物在 dist/dev/mp-weixin，可在微信开发者工具中导入)
npm run dev:mp-weixin

# 4. 生产环境打包
npm run build:h5
```
